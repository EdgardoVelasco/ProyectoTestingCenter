# Reglas de layout

Todos los valores son DERIVADOS y están IN_REVIEW.

- Contenedor de formulario: máximo propuesto 1280 px, centrado, padding 24–32 px escritorio y 16 px móvil.
- Grid: 12 columnas conceptuales; formularios usan dos columnas equivalentes cuando la lectura lo permite.
- Móvil: una columna; contenido nunca requiere scroll horizontal a 360 px.
- Observaciones, participantes, líneas de examen y resumen ocupan ancho completo.
- Header compacto: identidad/título/acción, sin consumir altura que oculte el formulario.
- Barra de acciones consistente; sticky solo si no cubre contenido/foco.
- Espacio usa escala `spacing-*`; no márgenes ad hoc.
- Orden DOM coincide con el orden visual y tabulación.
