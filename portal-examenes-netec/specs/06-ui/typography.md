# Tipografía

## Reglas oficiales

- Montserrat es la familia de uso general (manual p. 9).
- Se admiten variantes Thin, Light, Regular, Semibold y Bold mostradas por el manual; Medium aparece en la identidad (pp. 5, 9).
- La identidad usa tipografía sin patines; serif queda prohibida.
- Kollektif Italic no se usa como fuente general sin aprobación específica.

## Fallback y carga

`Montserrat, Arial, sans-serif` es la pila DERIVADA. Fuente local vs proveedor, subconjuntos, licencia y estrategia de preload: PENDIENTES. Nunca depender de una red pública sin decisión de seguridad/privacidad.

## Jerarquía derivada

| Rol | Tamaño/peso/line-height | Uso |
|---|---|---|
| Application title | 28–36 / 700 / 1.2 | Identidad del portal |
| Page title | 28 / 700 / 1.2 | Una vez por pantalla |
| Section title | 22 / 600 / 1.3 | Sección principal |
| Card title | 18 / 600 / 1.35 | Card |
| Body | 16 / 400 / 1.5 | Contenido |
| Label | 14 / 600 / 1.4 | Campo visible |
| Helper/error | 12–14 / 400–500 / 1.45 | Ayuda/validación |
| Table | 14 / 400–600 / 1.4 | Celdas/cabecera |
| Button | 14 / 600 / 1.2 | Acción; tracking 0.01em |

Tamaños, tracking y line-height son DERIVADOS. Thin no se usa en texto pequeño por legibilidad. No se comunica jerarquía solo por peso/color.
