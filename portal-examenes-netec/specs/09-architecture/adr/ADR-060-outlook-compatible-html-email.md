# ADR-060: HTML compatible con Outlook

Estado: APPROVED — 2026-07-24.

## Decisión

Usar tablas, estilos inline limitados al correo, fallback de fuentes y ancho máximo aproximado de 720 px. Generar text/plain independiente. No depender de Grid, Flexbox, JavaScript, imágenes externas ni CSS remoto.

## Consecuencias

Mayor compatibilidad con Outlook de escritorio, Web y móvil a cambio de una plantilla menos expresiva. Se requiere revisión visual manual en clientes disponibles.

## Validación

Previews de una solicitud, múltiples exámenes y múltiples monedas; prueba manual Outlook pendiente hasta Etapa D.
