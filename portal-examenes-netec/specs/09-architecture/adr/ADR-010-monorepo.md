# ADR-010: Monorepo
Estado: ACEPTADO para MVP. Contexto: equipo/producto único y contratos compartidos. Decisión: specs, SPA, API e infraestructura juntos. Alternativas: repos separados. Positivo: cambios atómicos/trazabilidad. Negativo: CI y permisos más amplios. Riesgo: crecimiento; pipelines por rutas y reevaluación por equipos autónomos.
