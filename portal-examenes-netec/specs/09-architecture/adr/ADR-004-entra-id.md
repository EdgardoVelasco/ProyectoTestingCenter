# ADR-004: Microsoft Entra ID
Estado: PROPUESTO (tenant/grupos pendientes). Contexto: identidad corporativa. Decisión: OIDC/JWT Entra. Alternativas: IdP propio/otro OIDC. Positivo: SSO y gobierno. Negativo: dependencia/configuración. Riesgo: claims variables; mitigar mapping configurable y pruebas.
